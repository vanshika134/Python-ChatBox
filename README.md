# 🤖 The Vanshika – Python Chatbot

**The Vanshika** is a rule-based chatbot built using Python. It can interact with users, remember their names during a session, answer basic questions, tell jokes, provide date and time information, and perform mathematical calculations.

## ✨ Features

- Interactive text-based conversation
- Remembers the user's name during a session
- Personalized and varied greetings
- Date and time responses
- Basic questions and predefined replies
- Random jokes
- Mathematical calculator
- Chat history saved to a text file
- Modular code using Python functions

## 🛠️ Technologies Used

- Python
- Random module
- Datetime module
- AST module
- Operator module

## ▶️ How to Run

1. Clone this repository.
2. Open the project folder.
3. Run:

```bash
python chatbot.py
```
